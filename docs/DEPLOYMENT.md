## ১. এখন কোথায় চলছে

| স্তর | কী | কোথায় |
|---|---|---|
| অ্যাপ সার্ভার | `node server.js` (পোর্ট 7788) | আপনার Windows মেশিন |
| পাবলিক HTTPS | Cloudflare Quick Tunnel (`cloudflared`) | `https://<random>.trycloudflare.com` |
| মডেল | Ollama + `qwen3.5:4b` | লোকাল CPU |
| স্টোরেজ | `data/` (JSON + JSONL) | লোকাল ডিস্ক |
| ব্রাউজার | Playwright + Chromium | লোকাল |
| সোর্স কোড | Git | GitHub `main` |

### কেন Vercel-এ পুরোটা চলে না (যাচাই করা সীমাবদ্ধতা)

| সমস্যা | কারণ |
|---|---|
| ফাইল সিস্টেম | Vercel serverless-এ `/tmp` ছাড়া লেখা যায় না, ফাংশন কোল্ড স্টার্টে সব হারায়। টাস্ক হিস্ট্রি/কী সেভ থাকবে না |
| দীর্ঘ কাজ | ৬০ সেকেন্ড (Hobby) — লোকাল মডেলের এক উত্তরই ৩০-৮৫ সেকেন্ড নেয় |
| SSE / লাইভ ইভেন্ট | ফাংশন শেষ হলে স্ট্রিম বন্ধ |
| Playwright | Chromium (~৪০০MB) ফাংশন প্যাকেজে চলে না |
| Ollama | আপনার মেশিনে, ইন্টারনেটে নয় |

তাই **Vercel শুধু ফ্রন্টএন্ড** হিসেবে কাজ করতে পারে, পুরো এজেন্ট সিস্টেম নয়। `vercel.json` ও `api/index.js` রিপোতে আছে — চাইলে স্ট্যাটিক ড্যাশবোর্ড হিসেবে ডিপ্লয় করা যাবে, কিন্তু টাস্ক/অনুমোদন/ব্রাউজার চলবে না।

## ২. পাবলিক URL চালু রাখা

```bash
# ১) সার্ভার
cd rakib-ai
node server.js            # অথবা start-rakib-ai.bat

# ২) টানেল (আলাদা টার্মিনাল)
cloudflared tunnel --url http://127.0.0.1:7788
```

`cloudflared` ইনস্টল না থাকলে:

```bash
npm exec --yes cloudflared -- tunnel --url http://127.0.0.1:7788
```

টার্মিনালে যে `https://....trycloudflare.com` দেখাবে সেটাই পাবলিক URL।
**সীমা:** Quick Tunnel-এর URL প্রতিবার বদলায়, এবং কম্পিউটার/প্রসেস বন্ধ হলে বন্ধ হয়ে যায়। ফ্রি, কোনো অ্যাকাউন্ট লাগে না।

### স্থায়ী URL চাইলে (ঐচ্ছিক, এখনো করা হয়নি)
- Cloudflare Named Tunnel — নিজের ডোমেইন লাগে
- Render / Railway / Koyeb ফ্রি টিয়ার — কিন্তু সেখানে Ollama নেই, রিমোট ফ্রি কী (OpenRouter/Groq) লাগবে

## ৩. ফ্রি ডিপ্লয়মেন্ট পথ (অ্যাকাউন্ট লাগে)

| প্ল্যাটফর্ম | কী চলবে | কী চলবে না |
|---|---|---|
| Vercel | স্ট্যাটিক UI, `/api/state` মতো হালকা রুট | টাস্ক, SSE, ব্রাউজার, ফাইল লেখা |
| Render (free web service) | পুরো Node অ্যাপ (৮০০ ঘণ্টা/মাস) | ১৫ মিনিট নিষ্ক্রিয় থাকলে ঘুমায়; ডিস্ক ephemeral; Chromium ভারী |
| Koyeb / Railway | পুরো Node অ্যাপ | ফ্রি টিয়ার সীমিত ঘণ্টা/ক্রেডিট |

**সুপারিশ:** ব্যক্তিগত ব্যবহারে লোকাল + Cloudflare টানেল সবচেয়ে সস্তা ও সম্পূর্ণ (ব্রাউজার + লোকাল মডেল + ফাইল সব কাজ করে)। সর্বজনীন, সবসময়-চালু চাইলে Render-এ ডিপ্লয় করে রিমোট মডেল কী দিতে হবে।

## ৪. Abacus AI ছাড়া ডেভেলপমেন্ট চালানো

| কাজ | কোথায় |
|---|---|
| কোড | GitHub `aiassistantrakib/rakib-ai` |
| কোড বদল | যেকোনো এডিটর, অথবা ChatGPT-তে কোড পেস্ট করে |
| টেস্ট | `npm test` / `npm run test:all` |
| সিকিউরিটি স্ক্যান | `npm run scan` |
| মডেল | Ollama (লোকাল), OpenRouter/Groq ফ্রি কী |
| ডিপ্লয় | `git push` → Render/Vercel |
| ডকুমেন্ট | `docs/` ফোল্ডার |

সব কনফিগ `lib/config.js`-এ, কোনো বাহ্যিক সার্ভিসের ওপর নির্ভরতা নেই (শূন্য npm রানটাইম ডিপেন্ডেন্সি)।
