## যা এখনো টেস্ট করা যায়নি (সৎভাবে)

- **ভিডিও জেনারেশন** — GPU নেই। টেস্ট করার মতো কোনো ফ্রি পথ নেই।
- **ব্রাউজার ক্লিক/ফর্ম** — Playwright ইনস্টল হয়নি (~৪০০MB + আপনার অনুমতি দরকার)।
- **OpenRouter/Groq ফ্রি key** — key ছাড়া শুধু ৪০১ যাচাই করা গেছে, আসল উত্তর নয়।
- **মোবাইল ADB, সোশ্যাল পোস্টিং, ডেস্কটপ কন্ট্রোল** — অনুমতি/নেটিভ হেল্পার ছাড়া চালু করা হয়নি (ডিজাইনেই বন্ধ)।
