# RAKIB AI — নিরাপত্তা অডিট

সব দাবি `tests/security.test.js`-এ প্রমাণিত (১৮টি পাস)। যা করা হয়নি তা "নেই" বলেই লেখা।

| ঝুঁকি | কী করা হয়েছে | প্রমাণ |
|---|---|---|
| অননুমোদিত ব্যবহার | প্রতিটি পরিবর্তনকারী API-তে `x-rakib-token`; টোকেন `data/access-token`-এ (৬০০ অনুমতি) | টোকেন ছাড়া → 401 |
| CSRF | `Origin` হোস্টের সাথে না মিললে → 403 | evil.example → 403 |
| পাথ ট্রাভার্সাল | `safePath()` — `..` ও absolute path ব্লক; `/files/` শুধু `workspace/` | `../../keys.json` → 404 |
| কোড এক্সিকিউশন | `node:vm`, ২ সেকেন্ড, `require`/`process`/`fs`/নেটওয়ার্ক নেই | require → Error, infinite loop → timeout |
| SSRF | `fetch_url` লোকাল/প্রাইভেট IP ও `file://` ব্লক | 127.0.0.1 → Error |
| ক্যালকুলেটর ইনজেকশন | `eval` নেই; নিজের লেখা পার্সার + অক্ষর whitelist | `constructor.constructor(...)` → throw |
| Secret লিক | key ফাইলে এনক্রিপ্টেড; লগে `redact()`; UI-তে `mask()` | লগে কোনো `sk-or-v1-…` নেই |
| ব্রুটফোর্স/স্প্যাম | ১২০ অনুরোধ/মিনিট/IP → 429 | ১৩০ অনুরোধে 429 |
| পাবলিক এক্সপোজার | ডিফল্টে `127.0.0.1`; `publicAccess` বন্ধ | — |
| Paid মডেল | গেটওয়ে শুধু `:free` ও লোকাল; paid আইডি কোডে রাউট হয় না | `models.every(m => m.free)` |
| অনিচ্ছাকৃত পাবলিক পোস্ট | সোশ্যাল এজেন্ট ব্লকড; নীতি: অনুমতি ছাড়া পোস্ট নয় | agents registry |

## যা এখনো নেই (সৎ তালিকা)
- **TLS/HTTPS** — লোকাল HTTP; ইন্টারনেটে খুলতে হলে রিভার্স প্রক্সি (Caddy/nginx) দরকার।
- **মাল্টি-ইউজার RBAC** — এখন একক ব্যবহারকারী (এক টোকেন)। একাধিক ব্যবহারকারী চাইলে আলাদা কাজ।
- **Key এনক্রিপশনের কী** — মেশিন-ভিত্তিক; ডিস্ক চুরি হলে সুরক্ষা সীমিত।
- **ভাইরাস স্ক্যান** — আপলোড করা ফাইল স্ক্যান হয় না (শুধু সাইজ/টাইপ সীমা)।
- **Prompt injection** — মডেল-স্তরে ১০০% ঠেকানো অসম্ভব; তাই টুলগুলো (ফাইল/নেটওয়ার্ক/শেল) স্যান্ডবক্সে সীমিত, এবং কোনো টুল নিজে থেকে পোস্ট/পেমেন্ট/ডিলিট করে না।
